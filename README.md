# CleanYourTV launcher for Charan's Onn 4K Streaming Box

Launcher source from https://github.com/Gathin23/cleanyourtv (MIT), `launcher/` folder,
with `config.xml` set for the Onn box: dock = Netflix, Prime Video, YouTube, Hotstar;
live_tv_package empty (streaming box, no tuner).
CI builds `app-release.apk` and uploads it as the `tvhome-apk` artifact.
